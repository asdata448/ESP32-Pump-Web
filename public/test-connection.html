⚙️ Cấu hình

📊 Trạng thái ESP32

Chưa kết nối. Nhấn TEST để lấy trạng thái.

📝 Hướng dẫn

1. Xác định IP ESP32:

  • Chế độ AP (mặc định): 172.20.10.9
  • Chế độ STA: Xem Serial Monitor Arduino IDE

2. Kết nối với ESP32:

  • Nếu ESP32 ở chế độ AP → Kết nối WiFi "ESP32_Pump"
  • Nếu ESP32 ở chế độ STA → ESP32 và computer phải cùng mạng WiFi

3. Test kết nối:

  • Nhấn nút TEST KẾT NỐI
  • Nếu thành công → sẽ thấy trạng thái ESP32
  • Nếu lỗi → kiểm tra lại IP và kết nối mạng

4. Test các lệnh:

  • Sau khi kết nối thành công, có thể test các lệnh
